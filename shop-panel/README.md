# Панель магазина — Flowers & Sweets (Душанбе)

Веб-панель для сотрудников магазина (планшет/ПК, от 768px). Vite + React + TypeScript, plain CSS, без UI-библиотек.

## Запуск

Требуется Node 22 и запущенный backend на `http://localhost:8000`.

```bash
npm install
npm run dev        # http://localhost:5173
```

Конфигурация — в `.env`:

```
VITE_API_URL=http://localhost:8000/api/v1
VITE_WS_URL=ws://localhost:8000/ws
```

## Скрипты

- `npm run dev` — dev-сервер (порт 5173)
- `npm run build` — `tsc -b` + production-сборка в `dist/`
- `npm run typecheck` — только проверка типов

## Вход

OTP по номеру телефона сотрудника магазина (роль `shop_staff`). В dev-режиме код
показывается подсказкой (поле `dev_code` ответа backend'а). Тестовый сотрудник:
`+992900000002`. Пользователи без роли `shop_staff` видят экран «Нет доступа».

## Что внутри

- **Входящие заказы** — realtime через WS `/ws/shop/` (звук + мигание карточки),
  polling fallback каждые 15 сек, таймер обратного отсчёта на принятие,
  принятие с выбором ETA (15/20/30/45 мин), отклонение с обязательной причиной.
- **В работе** — адрес и телефон получателя (доступны после принятия), кнопка «Заказ готов».
- **История** — все прошлые заказы со статусами.

Разделы «Товары», «Часы работы», «Финансы» не включены: соответствующие
endpoint'ы (`/shop/products/`, `/shop/hours/`, `/shop/finance/*`) в backend пока
не реализованы (404).
